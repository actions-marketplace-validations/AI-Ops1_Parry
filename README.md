## 🚀 What Parry Does

### 1. 🛡️ GitHub Marketplace PR Shield & SARIF Gatekeeper
Drop Parry into any GitHub CI workflow in 30 seconds.
- **Sticky PR Shield Comment**: Posts and updates a single sticky PR comment with deflected bugs, severity, and suggested replacements without spamming pull request activity.
- **AST Baseline Fingerprinting (`.parry-baseline.json`)**: Emits AST-relative SHA-256 fingerprints so PRs only fail on **net-new AI defects** introduced in the PR diff, never failing on pre-existing legacy code debt.
- **Native SARIF 2.1.0**: Directly populates the **GitHub Security / Code Scanning** tab with zero SaaS subscription dependencies.

```yaml
# .github/workflows/parry.yml
name: Parry PR Shield
on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read
  pull-requests: write
  security-events: write

jobs:
  parry-shield:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: AI-Ops1/Parry@v1
        with:
          paths: "."
          fail-on: "warning"
          comment-pr: "true"
          changed-only: "true"
          sarif-output: "parry-results.sarif"
      - uses: github/codeql-action/upload-sarif@v3
        if: always() && hashFiles('parry-results.sarif') != ''
        with:
          sarif_file: parry-results.sarif
```

### 2. ⚡ Turnkey AI IDE Hooks & Local MCP Server
Stop hallucinated packages and logic bugs before they ever reach a git commit.
- **1-Command Universal Setup**: Configure Cursor, Claude Code, Windsurf, VS Code, and Codex with one command:
  ```bash
  python parry.py install-hooks --ide all --instructions
  ```
- **Real-Time Post-Tool-Use Interceptor (<20ms)**: Hooks into Claude Code, Cursor, and Windsurf file edits to inspect and auto-repair AI changes the millisecond they are generated.
- **Git Staged Pre-Commit Hook**: Scans only modified files during `git commit` in under 15ms.
- **Zero-Dependency stdio MCP Server**:
  ```bash
  python parry.py mcp
  ```
  Exposes the `parry_verify_code` tool directly to Claude, Gemini, and Cursor so the model inspects and self-heals its own code before saving.

---

### 3. 🧠 Repo-Context Enforcement & Structural AI Slop Rules
Defend against prompt injections and eliminate lazy AI engineering habits.
- **Prompt Injection Defense for Context Files**:
  Scans `.cursorrules`, `AGENTS.md`, and `CLAUDE.md`. Normalizes Unicode homoglyphs and strips zero-width invisible character evasion attempts (`\u200B`, `\uFEFF`, soft hyphens) used to hijack coding agents.
- **Structural Slop Deflection**:
  - **Type Escape-Hatch Spikes**: Flags lazy type bypassing (`as any`, `@ts-ignore`, `@ts-nocheck`, bare `except: pass`, and unchecked `.unwrap()`).
  - **Loop N+1 Async Traps**: Catches unbatched `await fetch()` or database queries inside serial loops, suggesting `Promise.all` or `asyncio.gather`.
  - **Cross-File Code Duplication**: Warns when AI duplicates utility functions instead of reusing existing imports.
- **Human Review Focus Brief (`--review`)**:
  ```bash
  python parry.py check src/ --review
  ```
  Partitions findings into **Instant 1-Click Auto-Fixes** and an **Architectural Triage Brief** for human reviewers, cutting PR review fatigue.

## 💻 CLI Commands Reference

```bash
# --- BENCHMARKING & EVALUATION ---
python parry.py bench                     # Run 100-case Evil AI Benchmark
python parry.py bench --leaderboard       # Display 7-model comparative leaderboard
python parry.py bench --format markdown   # Output leaderboard as Markdown table

# --- CODE SCANNING & DEFLECTION ---
python parry.py check path/to/code        # Scan files or directories
python parry.py check --staged            # Scan only git staged files (< 15ms)
python parry.py check --diff-base origin/main # Scan only files changed in PR branch
python parry.py check --review            # Output Human Review Focus Brief
python parry.py check --web3-audit        # Run Web3 protocol security audit

# --- REPAIR & AUTO-FIX ---
python parry.py fix path/to/code          # Automatically repair deterministic defects in-place
python parry.py check path/to/code --fix  # Preview LLM prompt patches and diffs

# --- BASELINES & SILENCING LEGACY DEBT ---
python parry.py init --baseline .         # Generate .parry-baseline.json to mute legacy debt

# --- IDE HOOKS & MCP ---
python parry.py install-hooks --ide all   # Configure Cursor, Claude, Windsurf, Gemini, Codex
python parry.py install-hooks --ide claude --instructions
python parry.py post-edit <file>          # Real-time PostToolUse file check (< 20ms)
python parry.py mcp                       # Start stdio MCP JSON-RPC 2.0 server

# --- TEAM WEBHOOKS & CI INTEGRATION ---
python parry.py check --webhook-url <url> --team-enforce # Notify Slack/Discord on PR bugs
python parry.py check --format sarif --output parry.sarif # Export SARIF 2.1.0 for GitHub Security
```
